# Perfect Guess

Perfect Guess is a simple command-line number guessing game developed in Python. The computer randomly generates a number between 1 and 100, and the player attempts to guess the number. The game provides hints after each incorrect attempt, helping the player determine whether the next guess should be higher or lower.

## About the Project

The main purpose of this project is to practice fundamental Python programming concepts by building a simple interactive game. The program demonstrates random number generation, user input, loops, conditional statements, and basic game logic.

## How the Game Works

1. The computer generates a random number between 1 and 100.
2. The player enters a number as their guess.
3. The program compares the guess with the generated number.
4. If the guess is too high, the program asks the player to enter a lower number.
5. If the guess is too low, the program asks the player to enter a higher number.
6. The game continues until the correct number is guessed.
7. The total number of attempts is displayed at the end.

## How to Run

Clone the repository:

    git clone https://github.com/anushka-bhamare/the-perfect-guess.git

Navigate to the project directory:

    cd the-perfect-guess

Run the program:

    python main.py
